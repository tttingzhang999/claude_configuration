# Chinese Output

Applies whenever the output is Traditional Chinese — the surrounding content is Chinese, or the user asked for Chinese.

**Write Chinese from the facts. Do not make Chinese track English sentences.** An English draft in context is a source of facts, never a sentence template.

Outline requirements — rewrite, don't translate:

- Verbs: use an established Chinese verb, keep the English word, or describe the action in a short clause. Never coin a compound verb by calquing (推老 / 表面化 / 發查 / 騎在…上).
- One sentence, one point. Packing every exception into a single sentence is a virtue in English technical writing; in Chinese it breaks.
- Subject first; don't stack long modifiers ahead of it.
- Passive voice needs an agent — name the service or the code that acts.
- Use em dashes sparingly; turn parentheticals into a comma, a semicolon, or a new sentence.
- Put the weight of the sentence on the action, not on 「…的東西／的地方／的部分」.

Before emitting Chinese, re-read it against the list above.
