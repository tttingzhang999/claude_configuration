# 輸出模板（輸出格式章節用）

每則訊息固定**兩行**：第一行「分級 + 來源 + 標題」，第二行 `↳` 開頭放一句話摘要。訊息之間、區塊之間**都空一行**。**只輸出本次實際跑的來源區塊。**

## Gmail

```markdown
> 📧 **Gmail**（<HH:MM>–<HH:MM>，<N> 封）

🔴 <寄件人顯示名>｜<主旨（截斷）>
↳ <一句摘要 + 需要什麼動作>

⚪ <寄件人顯示名>｜<主旨（截斷）>
↳ <一句摘要>
```

## Slack

```markdown
> 💬 **Slack**（<HH:MM>–<HH:MM>，<N> 則）

🔴 <#頻道 或 DM · 發話人>｜<訊息開頭（截斷）>
↳ <一句摘要 + 需要什麼動作>（[原訊息](permalink)）

⚪ <#頻道 · 發話人>｜<訊息開頭（截斷）>
↳ <一句摘要>（[原訊息](permalink)）
```
